One single-line safety warning label that should come printed on every
human being — funny first, plausible second. The program writes the
line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).

## The line

> WARNING: This human will open the fridge, stare inside for a full minute, then close it having learned nothing.

111 characters, one line. The setup is a behaviour everyone recognises
in themselves; the turn lands in the last three words.

## Run locally

```
node main.ts
```

Node 22+, no dependencies, no network. Writes `entry.txt` to
`$OUTPUT_DIR` (default `/output`).
